# 軌道地圖 Orbital Atlas

*A collaborative project by roylin1003 and Claude.*

用太陽系簡圖＋規則式導覽小工具讀天文／太空新聞，順便學英文——每個難一點的生字都加了底線，滑過去（或點一下）就有英英解釋。純 HTML，不需安裝、不需伺服器。

**▶ 立即查看**：<https://orbital-atlas.roylin1003.workers.dev/>

> 目前為 **示範版**，內容是 2026-09-17 從 Universe Today 與 NASASpaceFlight.com 擷取的一份快照，**不是即時新聞**。
> 之後手動換文章時，這行日期跟 `index.html` 裡的 `SNAPSHOT_DATE` 常數要一起改——這個檔案不會自動同步。

---

## 這是什麼

- **太陽系地圖**：只有真的「有地點」的新聞才會釘在對應的行星旁邊——土星的新大氣結構、金星可能曾有過的衛星、月球塵埃裡的古文明線索、海王星外天體的表面顏色、一顆闖入太陽系的星際彗星 3I/ATLAS。其餘的火箭發射與任務新聞（Starship、Artemis、Soyuz……）本質上是時間表資訊，不硬塞進地圖，另外列成清單。
- **英英字典**：文章裡加底線的生字，滑過去會顯示一句話的英文解釋（自己寫的，不是抄字典）。
- **規則式導覽**：上方搜尋框輸入行星名、太空船名或任何關鍵字，比對標題與關鍵字算分找出最相關的文章——**沒有接任何 AI 模型**，純規則判斷，零成本、零延遲。

## 來源與素材

- 文章摘要皆為改寫，不是原文轉載；每篇都附「Read the original article →」連回來源網站。
- 行星圖像來自 Roy 自己的像素素材引擎 [pixel-forge](https://github.com/Roylin1003)（球面經緯度貼圖＋動態光影，不是九宮格拼貼）。
